# Food Track

Personal, mobile-first application for tracking diet, calorie/macronutrient intake, and weight progress.

Stack: React Native + Expo + TypeScript (frontend), .NET / C# REST API (backend), Firebase Authentication + Cloud Firestore (infrastructure).

Full implementation document (architecture, domain model, calculations, dashboard, MVP scope, roadmap): [docs/food-track-implementation.md](docs/food-track-implementation.md)
